## OpsBatch 1.0.3

### Fixes / 修复

* Linux: OpsBatch no longer crashes at startup on systems without the AppIndicator library (`libayatana-appindicator3`); it starts without a tray icon instead. The AppImage now also carries that library, and the .deb depends on it.
  Linux：在没有 AppIndicator 库（`libayatana-appindicator3`）的系统上，OpsBatch 不再于启动时崩溃，而是不带托盘图标继续运行。AppImage 现在自带该库，.deb 也声明了对它的依赖。
* Linux: the AppImage carries the other libraries it needs (xkbcommon, xcb extensions, Wayland, Vulkan loader, ALSA and what they depend on), so it starts on systems that do not have them installed.
  Linux：AppImage 自带其余所需的运行库（xkbcommon、xcb 扩展、Wayland、Vulkan 加载器、ALSA 及其依赖），在没有安装这些库的系统上也能启动。

macOS and Windows builds are unchanged apart from the version number.
macOS 与 Windows 版本除版本号外没有变化。
