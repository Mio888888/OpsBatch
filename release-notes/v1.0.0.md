## OpsBatch 1.0 — now a native Rust app / 原生 Rust 版本

OpsBatch is rebuilt in Rust on GPUI. It replaces the Tauri + React build and reads and writes the same data, so
nothing needs exporting: hosts, groups, scripts, libraries, workflows, settings and the encrypted vault carry over.
OpsBatch 用 Rust 与 GPUI 重写，取代 Tauri + React 版本，数据完全沿用，无需导出：主机、分组、脚本、库、工作流、设置和加密保险库都会保留。

### Updating from the Tauri build / 从 Tauri 版更新

* Installed Tauri builds are offered this update in the app; your data stays as it is.
  已安装的 Tauri 版会在应用内收到本次更新，数据保持不变。
* Do not run the Tauri build and this build at the same time; they share one database and vault.
  请不要同时运行两个版本，它们共用同一个数据库与保险库。
* macOS: a build that is not notarized by Apple needs `xattr -cr /Applications/OpsBatch.app` once.
  macOS：未经 Apple 公证的构建首次打开前需执行一次 `xattr -cr /Applications/OpsBatch.app`。

### What is new / 变化

* Native interface drawn by GPUI, with no WebView; the terminal, editor and workflow canvas are native too.
  界面由 GPUI 原生绘制，不再依赖 WebView；终端、编辑器和工作流画布也都是原生的。
* VNC: a native RFB client with None / VNC password / Apple ARD authentication picked automatically from what the
  server offers (a user name means ARD), Raw, CopyRect, Hextile and ZRLE encodings, pipelined updates and a tiled picture.
  VNC：原生 RFB 客户端，按服务器提供的方式自动选择认证（填写用户名即走 ARD），支持 Raw、CopyRect、Hextile、ZRLE，更新请求流水线化，画面分块绘制。
* RDP: IronRDP with H.264 and bitmap paths, clipboard, audio and drive redirection, batched input and a tiled picture.
  RDP：基于 IronRDP，H.264 与位图两条显示路径，剪贴板、音频、磁盘映射，输入批量发送，画面分块绘制。
* AI: provider, agent and safety settings, and an MCP bridge that lets external agents drive OpsBatch with per-call approval.
  AI：服务商、智能体与安全设置，以及让外部智能体在逐次审批下操作 OpsBatch 的 MCP 桥。
* Free-form workflow canvas with ports, zoom, pan and a minimap.
  自由画布的工作流编辑器，支持端口连线、缩放平移与小地图。
* Installers for macOS (Apple silicon, Intel), Windows and Linux are signed with the updater key and checked against `SHA256SUMS` before they are opened.
  macOS（Apple 芯片、Intel）、Windows、Linux 安装包均用更新密钥签名，打开前会用 `SHA256SUMS` 校验。

功能覆盖与和 Tauri 版的已知差异见 FEATURE_MATRIX.md。
