## OpsBatch 1.0.4

### Fixes / 修复

* Linux: windows now carry the application id `opsbatch` (X11 WM_CLASS / Wayland app id), which is what lets the desktop match them to the launcher entry and window-detection tools find them.
  Linux：窗口现在带有应用标识 `opsbatch`（X11 的 WM_CLASS / Wayland 的 app id），桌面环境据此把窗口与启动器条目对应起来，窗口检测工具也能识别它们。

macOS and Windows builds are unchanged apart from the version number.
macOS 与 Windows 版本除版本号外没有变化。
