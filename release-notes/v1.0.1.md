## OpsBatch 1.0.1

### Fixes / 修复

* Linux: the AppImage now carries the libraries it needs (xkbcommon, xkbcommon-x11, xcb extensions, Wayland, Vulkan loader, ALSA and the rest of what the app links to) and no longer fails to start with "error while loading shared libraries" on systems that do not have them installed.
  Linux：AppImage 现在自带所需的运行库（xkbcommon、xkbcommon-x11、xcb 扩展、Wayland、Vulkan 加载器、ALSA 等），在没有安装这些库的系统上不再因 “error while loading shared libraries” 而无法启动。
* The packaging step fails if the AppImage binary would still depend on a library that is neither bundled nor expected on every system.
  打包时若 AppImage 中的程序仍依赖既未打包、也不能指望每个系统都有的库，构建会直接失败。

macOS and Windows builds are unchanged apart from the version number.
macOS 与 Windows 版本除版本号外没有变化。
